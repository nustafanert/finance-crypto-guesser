# CoinCore: Crypto Guesser v2.4 📈

CoinCore is a modern, dark-themed Financial Analysis Terminal and Strategy Backtesting Simulator for cryptocurrency markets. It leverages technical analysis (TA) indicators to provide a live consensus on market trends and allows users to simulate custom trading strategies against historical data.

This project was developed as a university project by **Mustafa Mert Altinsoy, Omer Azam Aslan, and Suleyman Arda Kose**.

## ✨ Features

- **Interactive Financial Terminal:** A sleek, fully responsive web-based UI built with Streamlit and styled with custom CSS.
- **Multi-Indicator Consensus Engine:** Analyzes up to 13 different technical indicators simultaneously:
  - Trend: SMA Cross, EMA Cross, ADX, Parabolic SAR, Ichimoku Cloud
  - Momentum: RSI, MACD, Stochastic Oscillator, CCI, Williams %R, Awesome Oscillator
  - Volatility & Volume: Bollinger Bands, MFI (Money Flow Index)
- **Flexible Analysis Modes:**
  - *Conservative:* Only considers clear BUY signals.
  - *Balanced:* Factors in NEUTRAL signals to temper the consensus.
  - *Aggressive:* Strictly measures BUY vs SELL signals, ignoring neutrality.
- **Market Visualization:** Interactive candlestick charts powered by Plotly.
- **Strategy Backtester:** Simulate your selected indicator combination over a customizable time period. See every generated buy/sell signal, monitor simulated balances, and review overall profitability.
- **Offline Data Handling:** Built-in script to fetch and store data locally from the Binance API, avoiding rate limits during extensive backtesting.

## 🚀 Getting Started

### Prerequisites

Ensure you have Python 3.8+ installed. You can install the required dependencies using `pip`.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nustafanert/finance-crypto-guesser.git
   cd finance-crypto-guesser
   ```

2. **Create a virtual environment (optional but recommended):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

### Running the Application

1. **Download Historical Data:**
   Before running the app, you need to download the offline dataset to populate the charts and backtesting engine.
   ```bash
   python download_offline_data.py
   ```
   *This will fetch up to 1000 days of daily OHLCV data from Binance for supported pairs and save them in the `data/` directory.*

2. **Launch the Terminal:**
   ```bash
   streamlit run app.py
   ```

3. **Access the Web Interface:**
   Open your browser and navigate to `http://localhost:8501`.

## 🧠 How It Works

1. **Data Fetching (`data_fetcher.py`):** Loads the pre-downloaded CSV files into Pandas DataFrames.
2. **Technical Analysis (`strategy.py`):** Uses the `ta` library to compute indicator values for every candle. It also contains the core logic for the Consensus Engine and Backtest Simulator.
3. **User Interface (`app.py`):** The Streamlit frontend allows you to select trading pairs, toggle indicators on/off, set backtesting parameters, and visualize the results via Plotly graphs.
